# PixelRMMO

Page d'authentification (Connexion / Inscription) pour PixelRMMO — React + Vite + TypeScript + Tailwind CSS, avec un décor pixel art animé (ville médiévale de nuit, étang, lanternes, ciel étoilé) et une carte glassmorphism.

## Démarrer

```bash
npm install
npm run dev      # serveur de dev
npm run build    # build de production (tsc + vite build)
npm run lint      # oxlint
npm run preview  # prévisualiser le build
```

Voir `CLAUDE.md` pour l'architecture détaillée.
